The web app (`apps/web`) is a Next.js 15 application that provides the browser-based terminal interface. It communicates with the relay server over WebSocket using the `@repo/protocol` package.

## Key Features

- **xterm.js Terminal**: Full terminal emulation with WebGL rendering, search, and Unicode 11 support
- **Session Management**: Create, attach, rename, and kill tmux sessions
- **File Browser**: Browse directories and preview files on the remote host
- **Responsive Design**: Desktop sidebar layout and mobile tab-based navigation
- **Customizable**: Terminal themes, font sizes, cursor styles, keyboard toolbar keys
- **Offline Resilient**: Automatic reconnection with exponential backoff

## Tech Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 4
- shadcn/ui components
- Zustand for state management
- xterm.js for terminal rendering
