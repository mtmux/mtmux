## Tab Navigation

On mobile (screens under 768px), the app switches from a sidebar layout to a tab-based interface:

- **Terminal** — The terminal view with swipe-based session switching
- **Sessions** — Full session list with create/attach/kill
- **Files** — File browser with breadcrumb navigation
- **Settings** — Terminal and gesture settings

## Keyboard Toolbar

A customizable toolbar appears above the mobile keyboard with frequently-used keys:

- **Tab**, **Esc**, **Ctrl**, **Alt**
- Arrow keys (Up, Down, Left, Right)
- Special characters: `|`, `-`, `~`, `/`

Enable or disable individual keys in Settings.

## Gestures

Configure touch gestures in Settings:

| Gesture           | Action          | Default |
| ----------------- | --------------- | ------- |
| Swipe left/right  | Switch sessions | Enabled |
| Double-tap        | Copy selection  | Enabled |
| Long-press        | Context menu    | Enabled |
| Two-finger scroll | Scroll terminal | Enabled |

## Haptic Feedback

Toggle haptic feedback (vibration on key press) in Settings. This uses the Vibration API on supported devices.
